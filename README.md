# 物品演化史 · Object Evolution

一个以“数字博物馆”为方向的物品演化史网站。

## 第一件物品：手机

第一版从手机开始，用时间轴记录它从移动通信早期形态，到功能手机、触屏智能手机、全面屏，再到 AI 手机的发展过程。

## 计划中的收藏

- 📱 手机
- 🚗 汽车
- 💻 电脑
- 📷 相机
- 📺 电视
- ⌚ 手表

## 当前结构

这是一个零依赖的静态网站，方便先快速迭代内容与交互。核心文件：

- `index.html`：页面结构
- `styles.css`：视觉系统与响应式布局
- `app.js`：物品数据、时间轴与交互逻辑

## 下一步

后续可以逐件补齐真实历史资料、实物图片、关键人物与技术节点，并逐步加入更多物品，让网站从“手机时间轴”成长为完整的物品演化史博物馆。
